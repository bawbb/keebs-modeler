# Presets

- Every character setting can be saved together as a named preset and recalled later.
- A built-in default sound is always available to go back to, and can't be overwritten or deleted.
- Recalling a preset takes effect at once, even while notes are sounding.
- The player can see when the current sound has drifted from the preset it came from, and go back to it.
- Saving over a different existing preset, or deleting one, asks first. Re-saving the preset that is loaded just updates it.
- Presets made with an earlier version of the instrument still load: settings it no longer has are ignored, and new settings start at their defaults.
- The same presets can be used to render and measure sounds offline.
