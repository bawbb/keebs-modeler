# Keyboard Range

How the instrument's character changes from the lowest key to the highest.

- Every tone property can vary across the keyboard, not just be set globally.
- Transitions across the range are seamless — no audible break where one string type or string count gives way to another.
- The player chooses where transitions happen and how gradual they are (e.g. where wound strings give way to plain steel; where single, double, and triple strings are used).
- A sensible default exists that resembles a piano's layout.
